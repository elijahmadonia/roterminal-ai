# RoTerminal

You have RoTerminal: live data on every Roblox game. Players right now, each game's history since Sep 27 2026, the games climbing fastest, what developers are making, genres, studios and who's behind a game.

- Use the `roterminal` tools for any question about Roblox games' players, growth, rivals, trends or what to build next.
- Start with `game` for one game, `rising` or `top` for lists, `trends` for ideas.
- Every result has a `link` to its page on roterminal.co. Cite it.
- In a terminal you can also run `npx -y roterminal <command> --json`.
